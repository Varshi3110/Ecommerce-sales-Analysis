
# E-commerce Sales Data Analysis

## 1. Project Overview
This project analyses e-commerce sales data using Python.
The objective is to identify sales trends, top-performing
products, revenue-generating categories, customer locations,
and popular payment methods.

## 2. Business Objectives
- Calculate total sales revenue.
- Identify top-performing products.
- Analyse category-wise revenue.
- Identify high-revenue cities.
- Analyse monthly sales trends.
- Understand payment method preferences.

## 3. Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## 4. Dataset Description
The dataset contains 150 e-commerce orders and 12 original columns,
including order date, customer details, product, category,
quantity, unit price, discount, payment method, city and order status.

## 5. Data Cleaning and Preparation
- Checked missing values.
- Checked duplicate records.
- Checked duplicate Order IDs.
- Validated numerical values.
- Converted Order_Date into datetime format.
- Calculated Gross Revenue, Discount Amount and Net Revenue.

## 6. Data Analysis
- Order status analysis.
- Product-wise revenue analysis.
- Category-wise revenue analysis.
- City-wise revenue analysis.
- Monthly revenue analysis.
- Payment method analysis.

## 7. Key Business Insights
- Total delivered orders: 65.
- Total delivered net revenue: ₹6,63,750.
- Top product: Smartphone.
- Top category: Electronics.
- Top city: Bengaluru.
- Highest revenue month: June 2026.
- Most-used payment method: UPI.
- Highest payment-method revenue: Cash on Delivery.

## 8. Visualizations
Created five charts using Matplotlib and Seaborn:
1. Product-wise revenue.
2. Monthly revenue trend.
3. Category-wise revenue.
4. Payment method-wise revenue.
5. City-wise revenue.

## 9. Project Conclusion
This project demonstrates how Python can be used to clean,
analyse and visualise e-commerce sales data.

The findings help identify important products, categories,
cities and sales trends to support business decisions.
